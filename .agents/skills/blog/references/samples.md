## 跨篇认识变化

写 Agent memory、复利知识或经验抽象时，对照 [亲眼见证程序员职业的终结](../../../../source/_posts/the-compounding-ai-thesis.md) 中的持久化知识与 [长期记忆正在把 Agent 变蠢](../../../../source/_posts/faulty-agent-memory.md) 中的连续改写。两篇分别讨论外化知识的价值和总结污染的风险，存在需要解释的条件差异。不要自动宣布前文全错，也不要隐藏张力；先核验新证据，再说明哪条假设保留、哪条需要修改。

## 使用边界

继续在 `source/_posts/` 搜索本次主题的相关旧文，不能仅依赖这几个固定样本。提取观察、判断、证据与适用条件；新稿引用旧文时使用 Hexo `post_link`。当前格式与作者明确偏好优先于历史样例，英文表达也应直接读相应英文原文。

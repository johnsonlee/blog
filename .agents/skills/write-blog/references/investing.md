# Investing 类文章

Investing 类文章仍然先讲清一个产业、公司或资产如何运转。文章是否在做 alpha 分析，应由问题选择、证据和 economics 落点体现，不靠反复出现“投资”“投资者”“机会”或“alpha”。

## 论证链

根据主题选择合适的链路，不机械填满 checklist：

1. 需求由什么具体行为、合同或预算形成
2. 供给需要复制什么能力，时间和刚性在哪里
3. 哪个约束会影响交付、价格或竞争格局
4. 谁控制客户绕不开的环节，替代路径是什么
5. 约束如何传导到订单、backlog、价格、毛利、现金流或资本开支
6. 市场已经计入多少，什么事实会证伪判断

技术解释必须继续走到经济结果，财务判断也必须能沿事实链返回技术或交付约束。不要在两者之间插入“接下来讨论投资价值”之类的路标。

## 证据边界

- 区分公告、意向、合同、在建、已交付、已验收和投入使用；选择与主题相关的状态，不把它们混成“落地”。
- 区分存量、增量、run rate、目标、估算和合同上限，避免重复计算。
- 把公司披露、第三方估算和作者推论分别标清。
- 当前瓶颈不自动等于错误定价。需要单独判断持续时间、价值捕获和 price-in 程度。
- 不为了显得完整罗列所有供应商、股票或风险；只保留推动当前判断的证据。

## 语气

像拆一笔生意一样讲故事。合同、产能、交期、替代、定价和现金流自己会说明文章在算什么，不需要类别标签替它们发言。
